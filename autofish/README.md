# Simple AutoFish

魚が掛かったら自動で釣り上げ、そのまま自動で投げ直す、Minecraft 26.3 用の
**クライアント専用** Fabric MOD です。反応時間・再キャスト時間は Mod Menu の設定画面から
変えられます。数値を決めるのが面倒な人向けに、**人っぽくばらつく「おまかせランダム」**
も用意しています（初期設定はこれです）。

## 必要環境

| 項目 | バージョン |
| --- | --- |
| Minecraft | 26.3 |
| Fabric Loader | 0.20.1 以上 |
| Fabric API | 0.166.2+26.3 で確認 |
| Mod Menu | 21.0.1 で確認（任意。設定画面を開くのに使います） |
| Java | 25 |

## 使い方

1. `mods` フォルダに `simpleautofish-1.0.0.jar`、Fabric API、（設定したい場合は）Mod Menu を入れます。
2. 釣り竿を持って、**最初の1回だけ自分で投げます**。
3. あとは魚が掛かるたびに自動で釣り上げ → 少し待って自動で投げ直し、を繰り返します。

MOD が自分から釣りを始めることはありません。竿を持ち替える・自分で竿を上げると止まります。
インベントリやチャットなどの画面を開いている間は、閉じるまで操作を待ちます。

ON/OFF を切り替えるキーは「設定 → 操作設定 → キー割り当て → Simple AutoFish」で割り当てられます
（初期状態は未割り当て）。

## 設定（Mod Menu → Simple AutoFish → 設定ボタン）

| 項目 | 説明 |
| --- | --- |
| 自動釣り | MOD 全体の ON/OFF |
| 自動再キャスト | 釣り上げた後に自動で投げ直すか。OFF だと釣り上げるだけ |
| 釣り竿の保護 | 耐久値が残り 3 以下になったら投げ直さずに自動釣りを OFF にする |
| 反応時間 | 魚が掛かってから釣り上げるまでの時間 |
| 再キャスト時間 | 釣り上げてから次に投げるまでの時間 |

反応時間・再キャスト時間はそれぞれ 3 つのモードから選べます。

| モード | 動き |
| --- | --- |
| **ランダム (おまかせ)** | 設定不要。人の操作に近い、平均付近に集まる自然なばらつきで毎回決めます。<br>反応時間: 約 160〜650 ms（平均 320 ms）／再キャスト: 約 450〜2200 ms（平均 950 ms） |
| ランダム (範囲指定) | 最小〜最大の間から毎回ランダム（一様分布）に選びます |
| 固定 | 毎回同じ時間。スライダーで 10 ms 単位で設定 |

- 反応時間は 0〜1000 ms、再キャスト時間は 0〜5000 ms の範囲で設定できます。
  バニラでは魚が食いついている時間は 1〜2 秒なので、反応時間を長くしすぎると逃げられます。
  逃げられた場合はそのまま次の当たりを待ちます。
- 「完了」で保存、「キャンセル」で破棄します。設定は `config/simpleautofish.json` に保存されます。

> **注意**: マルチプレイサーバーによっては自動釣りが禁止されています。使う前にサーバーのルールを確認してください。

## 仕組み

- 当たりの判定は、サーバーから同期される釣りウキの `biting` フラグ（`FishingHook.DATA_BITING`）を
  Mixin の Accessor で読んでいます。音やパーティクルに頼らないので、音量 0 でも動きます。
- 釣り上げ・投げ直しは、バニラの右クリック処理（`Minecraft#startUseItem` のアイテム使用部分）と
  同じく `MultiPlayerGameMode#useItem` を呼び、腕振りも同じ条件で行います。

## ビルド

Java 25 が必要です。

```bash
./gradlew build
```

`build/libs/simpleautofish-1.0.0.jar` ができます。

### 自動テスト

実際にクライアントを起動してワールドを作り、手で1回投げた後に MOD が
「各タイミングモードで釣り上げ → 再キャスト」を 4 回繰り返すこと、
耐久値の少ない竿では投げ直さずに停止することを確認する Fabric クライアントゲームテストがあります。

```bash
./gradlew runClientGameTest
```

画面のないマシンでは `xvfb-run` などで仮想ディスプレイを用意してください。
Mesa のソフトウェアレンダラーで動かす場合、Xvfb の GLX は sRGB 対応のビジュアルを持たないので
`SDL_VIDEO_FORCE_EGL=1` を付けます。

```bash
SDL_VIDEO_FORCE_EGL=1 xvfb-run -a -s "-screen 0 1280x720x24" ./gradlew runClientGameTest
```
