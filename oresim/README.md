# OreSim (Minecraft 26.3 / Fabric)

ワールドシードからバニラの鉱石生成を再計算し、読み込まれているチャンクの鉱石位置を
ワイヤーフレームの箱で表示する **クライアント専用** Fabric MOD です。

ビルド済み jar: [`release/oresim-1.0.0+mc26.3.jar`](release/oresim-1.0.0+mc26.3.jar)

## 必要環境

| 項目 | バージョン |
| --- | --- |
| Minecraft | 26.3 |
| Fabric Loader | 0.20.1 以上 |
| Fabric API | 0.166.2+26.3 で確認 |
| Java | 25 (26.3 の要件) |

`.minecraft/mods/` に Fabric API と一緒に置いてください。サーバーには不要です。

## 使い方

- **シングルプレイ**: シードは自動で取得されます。入るだけで表示されます。
- **マルチプレイ**: `/oresim seed <シード>` でシードを設定します(サーバーのアドレスごとに
  `config/oresim.json` に保存)。数値でも文字列でも可(文字列はバニラと同じ方法で数値化)。

| コマンド | 内容 |
| --- | --- |
| `/oresim` | 状態表示(シード・範囲・表示中の鉱石・計算済みチャンク数) |
| `/oresim seed <シード>` | このサーバーのシードを設定 |
| `/oresim on` / `off` / `toggle` | 表示の有効・無効 |
| `/oresim range <1-32>` | 計算・表示するチャンク半径(初期値 5) |
| `/oresim ore <名前>` | 鉱石ごとの表示切替 |
| `/oresim hideair` | 既に掘られて空気になった位置を隠すか(初期値 ON) |
| `/oresim xray` | 壁越し表示の切替(初期値 ON) |
| `/oresim reload` | キャッシュを消して再計算 |

鉱石名: `diamond` `ancient_debris` `emerald` `gold` `iron` `redstone` `lapis`
(以上は初期表示 ON)、`copper` `coal` `nether_gold` `quartz`(初期 OFF)。

## 仕組み

- 地物の一覧・ステップ内の並び順・配置モディファイア(回数、高さ分布、レアリティ、
  バイオームフィルタ)は、ゲーム本体の `VanillaRegistries`(バニラのデータパックを生成する
  ブートストラップコードそのもの)から取得します。自前の鉱石テーブルは持っていません。
- チャンクごとの乱数は `ChunkGenerator#applyBiomeDecoration` と同じく
  `setDecorationSeed` → `setFeatureSeed(index, step)` で再現しています。
- 鉱石の塊の形は `OreFeature` / `ScatteredOreFeature` の処理を 1 行ずつ写したもので、
  「置き換え可能な岩か」「空気に接しているか(破棄確率)」の判定には今見えている
  ワールドのブロックを使います。鉱石ブロックは元の岩(石/深層岩/ネザーラック)に
  戻して判定するので、アンチXrayで鉱石が石に置き換えられていても結果は変わりません。

## 精度(26.3 実サーバーで検証)

専用サーバーで既知シードのワールドを生成し、19×19 チャンクについて
シミュレーション結果と実ブロックを 1 ブロックずつ照合しました(2 シード)。

| 鉱石 | 予測の正解率 | 実在鉱石の検出率 |
| --- | --- | --- |
| ダイヤモンド | 99.8% | 99.9% |
| 古代の残骸 | 100% | 99.3〜99.7% |
| レッドストーン | 99.97〜100% | 99.97〜100% |
| ラピスラズリ | 99.7% | 99.8% |
| 金 | 99.2〜99.3% | 99.3% |
| 鉄 | 99.9% | 97.6〜99.9% ※ |
| 銅 | 99.7〜99.8% | 90.0〜99.6% ※ |
| 石炭 | 97.8〜97.9% | 97.8〜98.1% |
| ネザー金 / クォーツ | 99.9% 以上 | 99.9% 以上 |

※ 取りこぼしは全て「鉱脈(ore vein、銅は Y 0〜50、鉄は Y −60〜−8)」の範囲内です。
鉱脈は地物ではなく地形ノイズで作られるため、このMODの対象外です。

## 制限事項

- 対象はバニラ 26.3 のオーバーワールドとネザーのみ。データパックや MOD で地形・鉱石を
  変えているサーバー、大きなバイオーム/アンプリファイドなどのワールドタイプでは一致しません。
- 「空気に接していると破棄」の判定は現在のワールドを見るため、プレイヤーが掘った場所の
  周辺では結果がずれることがあります。
- サーバーでの使用はそのサーバーのルールに従ってください。多くのサーバーでは
  Xray 系の MOD は禁止されています。

## ビルド

```bash
./gradlew build
```

`build/libs/oresim-1.0.0.jar` ができます。Java 25 で実行してください
(Gradle 9.9 はラッパーが取得します)。

`./gradlew runVerify` で上記の精度検証(専用サーバーを起動して照合)を実行できます。
`run-verify/eula.txt` に Minecraft EULA への同意が必要です。
